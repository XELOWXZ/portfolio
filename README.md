#  My Portfolio & Resume Website

เว็บไซต์พอร์ตโฟลิโอและเรซูเม่ส่วนตัวของผมครับ สร้างขึ้นเพื่อรวบรวมผลงาน ทักษะ และประวัติการทำงาน เพื่อใช้ในการนำเสนอตัวเอง

## 📌 โครงสร้างเว็บไซต์
- **About Me:** แนะนำตัวและแนวทางในการทำงาน
- **Skills & Experience:** ทักษะความสามารถและเครื่องมือที่ใช้งาน
- **Projects:** รวมโปรเจกต์และผลงานที่เคยพัฒนา
- **Contact:** ช่องทางการติดต่อ

## 💻 Tech Stack
- HTML5, CSS3, JavaScript
- (ระบุเครื่องมือหรือเฟรมเวิร์กอื่นๆ ที่ใช้ เช่น React, Vue, Tailwind)
